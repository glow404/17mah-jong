## 字体与麻将牌面

- 仓库没有分发 `.woff`、`.woff2`、`.ttf` 或 `.otf` 字体文件。
- 界面使用 CSS 系统字体栈，由访问者操作系统与浏览器提供字形。
- 麻将牌面使用 Unicode Mahjong Tiles 字符，而不是复制的第三方位图素材。不同平台显示的具体字形由各自系统字体许可覆盖，仓库不重新分发这些字体。

## 音乐与音效

- 仓库没有分发 `.mp3`、`.wav`、`.ogg` 或其他音频文件。
- 背景音乐、舍牌音效和荣和音效均由项目代码通过 Web Audio API 在运行时合成，不使用第三方录音或曲库。

## 新增资源要求

贡献者新增图片、字体、音频或视频时，必须在本文件中记录作者、原始链接、许可证、必要的署名方式以及是否允许修改和再分发。许可证不明确、仅限个人使用或与 MIT 项目分发不兼容的资源不得合入。
