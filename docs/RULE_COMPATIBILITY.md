# 规则兼容矩阵

最后更新：2026-10-05

本项目是“日麻启发”的二人自定义规则。下表把当前规则引擎与标准日本麻将（包括雀魂常见规则）的关系写清楚，避免测试或贡献误把差异当成回归。

| 规则/役种                                                                  | 17mah-jong                                               | 标准日本麻将/雀魂                   | 兼容性                 |
| -------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------------------------- | ---------------------- |
| 两立直                                                                     | 首次舍牌固定计 2 番                                      | 满足条件后宣告双立直，通常计 2 番   | 部分一致               |
| 断幺九、平和、一杯口                                                       | 支持                                                     | 支持                                | 一致（本项目仅荣和）   |
| 役牌、自风                                                                 | 固定东家/西家并计算自风                                  | 按场风、门风计算                    | 部分一致               |
| 三色同顺、三色同刻、一气通贯                                               | 支持                                                     | 支持                                | 一致                   |
| 对对和                                                                     | 规则分支已保留；当前无副露状态，四暗刻会优先作为役满结果 | 支持，副露/门清均可能出现           | 部分一致               |
| 三暗刻                                                                     | 支持                                                     | 支持                                | 一致                   |
| 混老头、混全带幺九、纯全带幺九                                             | 支持                                                     | 支持                                | 一致（番符模型不同）   |
| 混一色、清一色                                                             | 支持                                                     | 支持                                | 一致                   |
| 七对子                                                                     | 支持，固定 25 符                                         | 支持，固定 25 符                    | 一致                   |
| 小三元                                                                     | 支持                                                     | 支持                                | 一致                   |
| 国士无双、大三元、四暗刻、字一色、绿一色、清老头、小四喜、大四喜、九莲宝灯 | 支持，按役满倍率结算                                     | 支持                                | 一致（不实现多倍役满） |
| 宝牌/里宝牌                                                                | 表宝牌计算；荣和成立后公开里宝牌指示牌                   | 支持，里宝牌需立直和牌              | 部分一致               |
| 和牌方式                                                                   | 仅荣和                                                   | 荣和与自摸                          | 不同                   |
| 副露                                                                       | 不支持吃、碰、杠                                         | 支持吃、碰、杠                      | 不同                   |
| 摸牌流程                                                                   | 从个人剩余 21 张中自由选择舍牌                           | 从牌山摸牌后舍牌                    | 不同                   |
| 起胡门槛                                                                   | 必须满贯或以上                                           | 通常至少 1 个役即可和牌             | 不同                   |
| 振听                                                                       | 永久振听、临时振听                                       | 还包含同巡、立直等完整细则          | 部分一致               |
| 流局                                                                       | 双方各舍 17 张仍无人荣和                                 | 牌山耗尽或特殊流局                  | 不同                   |
| 结算                                                                       | 底分 × 满贯/跳满/倍满/三倍满/役满倍率                    | 基本点、庄闲、自摸/荣和、本场、供托 | 不同                   |

## 测试对应关系

- `tests/rules-matrix.test.ts`：普通役、役满、番符边界、宝牌/里宝牌、座风、非法牌和种子随机牌墙。
- `tests/mahjong.test.ts`：基础牌面、听牌、振听和推荐牌池回归。
- API 的第 17 张流局、放弃荣和后继续出牌以及联机状态转换仍属于应用层测试范围；新增回归时应同时覆盖 CPU 和联机两条路径。
