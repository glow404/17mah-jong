# 性能基线

## 本地开发基线（2026-10-05）

这是可重复的本机参考值，不是生产 SLO。机器/浏览器/浏览器缓存、Node/Vite 版本和本地 D1 状态都会影响结果；不要把它与 Cloudflare 全球真实用户性能直接比较。

环境：Windows 本地开发服务器，Node.js `v24.15.0`，Vite `8.0.13`，本地 D1；规则基准由同一 Node 进程执行。Playwright 页面探针排除 3 次预热，随后采集 20 个 warm-context 样本。

### 规则计算

执行：`npm run perf:rules`，2,000 次计时样本/操作，报告微秒。

| 操作                                 |      P50 |       P95 |       P99 |
| ------------------------------------ | -------: | --------: | --------: |
| `waitTypes`（13 张听牌手牌）         | 46.20 μs | 107.80 μs | 193.50 μs |
| `evaluateWin`（14 张未达到胡牌档位） |  8.80 μs |  17.80 μs |  47.70 μs |
| `evaluateWin`（14 张和牌）           |  0.70 μs |   1.20 μs |   1.60 μs |

### 页面与网络探针

执行：本地 `npm run dev -- --hostname 127.0.0.1 --port 3000` 后运行 `PERF_BASE_URL=http://127.0.0.1:3000 npm run perf:baseline`。页面值为浏览器 `loadEventEnd`；HTTP 值为页面内同源 `GET /api/health` 的往返时间，包含本地浏览器和开发服务器开销。

| 指标               |       P50 |       P95 |       P99 | 样本 |
| ------------------ | --------: | --------: | --------: | ---: |
| 首页 load event    | 102.30 ms | 114.70 ms | 115.60 ms |   20 |
| `/api/health` 往返 |  36.70 ms |  41.20 ms |  43.40 ms |   20 |

此接口仅作为稳定网络探针，不代表需要身份认证的 `/api/rooms` 长轮询。生产 API P50/P95/P99 应使用 [`OPERATIONS.md`](OPERATIONS.md) 中 Analytics Engine 查询采集，并同时记录 Worker 版本、时间窗口和流量。发布联网同步优化时，应再使用双浏览器 E2E/浏览器 trace 测房间快照的实际请求间隔、往返时间和状态可见延迟。

## 重测与比较

同一台机器比较规则算法改动时使用同 Node 版本、相同 fixture 和 `PERF_ITERATIONS`；比较页面时使用相同浏览器、服务端模式、缓存策略、预热数和样本量。至少记录 P50/P95/P99 与样本量。此处样本数较小，P99 近似最大观测值，不作为统计承诺。生产目标应在首次部署后从真实流量建立，随后基于实际业务定 SLO 和告警阈值。
